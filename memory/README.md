# Memory - 三层记忆与经验体系

> CMO-HKBQSKILL 的核心知识库，支持用户手动添加经验教学。

## 三层架构

```
memory/
├── hot/           ← 当前会话教训（临驻上下文）
├── warm/          ← 近期高频教训
├── cold/          ← 长期教训库（按根因归类）
├── TEMPLATES/     ← 用户贡献模板
├── skill/         ← Skill 优化追踪
└── user/          ← 用户手动添加区
```

### HOT - 当前会话

- 本会话激活的教训要点
- 临驻上下文，不占长期空间
- 会话结束归档到 WARM

### WARM - 跨会话

- 近期高频教训记录
- 跨会话项目状态
- 定期整理归档到 COLD

### COLD - 长期知识

- 教训库（按根因归类）
- `lesson-root-causes.md` - 教训本体
- `lesson-index.md` - 教训索引
- **永不删除，仅归档**

---

## 用户贡献区 (`user/`)

支持用户手动添加经验教学：

| 目录 | 说明 | 模板 |
|------|------|------|
| `01_个人经验/` | 个人原创经验 | `TEMPLATES/01-经验模板.md` |
| `02_成功案例/` | 验证通过的成功案例 | `TEMPLATES/02-成功案例模板.md` |
| `03_踩坑记录/` | 错误教训记录 | `TEMPLATES/03-错误教训模板.md` |

### 添加新经验

1. 复制对应模板到 `user/` 目录
2. 重命名为描述性名称
3. 填写内容
4. 经验自动纳入教训库

---

## 教训库索引

查看 `cold/lesson-index.md` 获取完整教训索引。

教训按 3 大根因分类：

| 分类 | 说明 |
|------|------|
| Lua 幻觉 | AI 编造了不存在的 API/参数 |
| 地理坐标 | 经纬度/altitude 值或参数名错误 |
| 意图理解 | 未正确理解用户需求导致方向错 |

---

## 自动错误捕获

当检测到以下模式时，系统会询问是否记录教训：

- 用户粘贴 Lua 报错：`ScenEdit_AddUnit 0 : ,xxx`
- 关键词：`记住这个错误`、`记录教训`、`报错`

### 手动收集

使用 `/cmo-errors` 命令收集错误：

```
/cmo-errors        # 交互式收集
/cmo-errors add   # 快速添加
/cmo-errors list  # 查看教训列表
```

---

## 维护规则

1. 会话结束时，HOT → WARM
2. 定期整理 WARM → COLD
3. COLD 永不删除，仅归档
4. 用户贡献随时可添加
