# Memory - 三层记忆体系

## 层级说明

| 层级 | 目录 | 内容 | 生命周期 |
|------|------|------|----------|
| HOT | `memory/hot/` | 当前会话上下文 | 会话内 |
| WARM | `memory/warm/` | 近期项目状态 | 跨会话 |
| COLD | `memory/cold/` | 长期知识沉淀 | 永久 |

## 使用指南

### HOT - 当前会话
- 当前用户需求
- 当前生成进度
- 当前调试状态

### WARM - 跨会话
- 项目进度
- 用户偏好
- 常见模式

### COLD - 长期知识
- 成功案例
- 错误教训
- 最佳实践

## 维护规则

1. 会话结束时，HOT → WARM
2. 定期整理 WARM → COLD
3. COLD 永不删除，仅归档
