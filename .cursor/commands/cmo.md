# CMO 命令

CMO 兵棋 Lua 代码生成的命令入口。

## 可用命令

| 命令 | 说明 |
|------|------|
| `/cmo` | 完整的 CMO Lua 代码生成工作流 |
| `/cmo-unit` | 快速添加单位 |
| `/cmo-query` | 数据库查询 |
| `/cmo-mission` | 任务生成 |
| `/cmo-check` | 代码自检 |

## 使用方式

```
/cmo 生成一个蓝方 F-16C 战斗机中队
/cmo-unit 添加红方 055 驱逐舰到舟山海域
/cmo-query 查询现役驱逐舰
/cmo-mission 创建巡逻任务
/cmo-check 检查我生成的代码
```
