## 关键官方 API 要点（防幻觉红线）

> 以下内容全部来自官方文档，任何与此不符的代码都是幻觉。

### ScenEdit_AddUnit

- `type` 官方示例值：`'Air'`（非 `Aircraft`），`'Ship'`，`'Sub'`
- 坐标参数：`Lat` / `Lon` / `alt`（官方示例），`latitude` / `longitude`（别名也有效）
- Aircraft 必须有 `loadoutid`（小写 l）
- `proficiency` 值：`'Novice'`, `'Cadet'`, `'Regular'`, `'Veteran'`, `'Ace'`

### ScenEdit_AddSide

- **官方文档明确**：`side` 是唯一官方参数
- `name` 作为 `side` 的别名是历史兼容 bug，**不应依赖**
- 官方示例：`ScenEdit_AddSide({side='OPFOR'})`

### ScenEdit_SetSidePosture

- **位置参数**：`ScenEdit_SetSidePosture(sideA, sideB, posture)`
- posture 值：`'H'`（敌对）, `'F'`（友好）, `'N'`（中立）, `'U'`（不友好）

### ScenEdit_AddMission

- **位置参数**：`ScenEdit_AddMission(SideNameOrId, MissionNameOrId, MissionType, MissionOptions)`
- MissionType 官方示例用**小写**：`'strike'`, `'patrol'`, `'mining'`, `'cargo'`, `'ferry'`, `'support'`, `'mineclearing'`
- mission type 官方示例用**小写**：`'air'`, `'land'`, `'sea'`, `'sub'`

### ScenEdit_SetMission

- **位置参数**：`ScenEdit_SetMission(side, name, options)`
- 官方文档未记录第三个位置参数是 MissionOptions 表

### ScenEdit_GetUnit

- **表参数**：`ScenEdit_GetUnit({side="xxx", unitname="yyy"})` 或 `ScenEdit_GetUnit({guid="..."})`
- **位置参数**：`ScenEdit_GetUnit(side, unitname)` 也有效

### VP_GetSides / VP_GetSide

- `VP_GetSides()` 无参数，返回阵营数组
- `VP_GetSide({Side="xxx"})` 表参数（大写 S）

### ScenEdit_SetEMCON

- `ScenEdit_SetEMCON("Side", "Blue", "Radar=Active")` — 第一参数是类型字符串
- 级别：Side / Mission / Unit / Group

### ScenEdit_AssignUnitToMission

- **位置参数**：`ScenEdit_AssignUnitToMission(unitNameOrGuid, missionNameOrGuid)`
- 官方文档未记录表参数形式
